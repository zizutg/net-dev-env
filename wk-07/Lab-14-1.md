Transport Layer Reliable Delivery

# Overview

This exercise provides basic overview of UDP Protocol and its message
delivery.

# Learning Objectives

- Understand basics of Reliable Transport Layer

- Understand Stop N Wait Protocol

- Understand Go Back N protocol

# Learning Resources

## Books

# Environment

This exercise is done using pen and paper and thus no computing
resources are required.

# Description

## Stop_n_Wait Protocol

Consider two hosts use Stop_N_Wait protocol, and Host A sends a total of
7 application messages to Host B. The network is lossy and every 3^rd^
packet from A to B is lost whereas every 4^th^ ack from B to A is lost.
Draw a Timeline sequence diagram showing the data segments and the acks
sent along with the corresponding sequence and ack numbers so that B is
able to receive all of the 7 application messages.

## Go-Back-N (GBN) Protocol

Consider two hosts use GBN protocol with window size of 3 and sequence
number range is from 0 to 6. Assume Host A sends a total of 7
application messages to Host B. The network is lossy and that 2^nd^ and
4^th^ packet from A to B are lost whereas 3^rd^ ack from B to A is lost,
i.e., two messages from A to B are lost and 1 ack from B to A is lost.
Draw a Timeline sequence diagram showing the data segments and the acks
sent along with the corresponding sequence and ack numbers so that B is
able to receive all of the 7 application messages.

### Extra Exercise

Suppose Host A and Host B use GBN protocol with window size of 4 and
sequence number range from 0 to 7. Assume Host A sends a total of 7
application messages to Host B and that every 4^th^ message from A to B
is lost, but all acks from B are received properly i.e. no ack from B to
A is lost. Draw a Timeline sequence (TLS) diagram showing the data
segments and the acks sent along with the corresponding sequence and ack
numbers, respectively. You can stop drawing the TLS after 12^th^ pkt
from A to B. Will A be able to send all the application messages
successfully?

## Selective Repeat (SR) Protocol

Consider the scenario given above in section
[5.2](#go-back-n-gbn-protocol), but hosts use Selective Repeat (SR)
instead of GBN Protocol. Draw the timeline sequence diagram for this
communication using SR protocol
