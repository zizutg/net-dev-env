Here you will find docker compose files to implement various exercises related to Computer Network and Security. 
- These exercises enables any learner to use the experiential learning, i.e. learn by doing it, to understand the key concepts in network and security

All the docker compose files have extension .yml. 
- The filename prefix arm64 corresponds to implement these experiments on Mx (ARP) chip based host system e.g. Apple Macbook and 
- prefix amd64 corresponds to implement these exercises in X86 based hosts. 

These exercises can be carried out under Docker desktop of Windows, Macbook. 
- Also, these can be carried out in Ubuntu (or any other Linux) based system.
